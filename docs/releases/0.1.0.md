First public build of fala, an Android tutor for practising a language by chatting.

## What it does

- You write in the language you are learning; the tutor corrects the message (what was wrong and why, in English) and replies to keep the conversation going. Replies stream in as they are written.
- Languages: Portuguese (Brazilian), Spanish, French, Italian, German. Levels A1 to C2.
- Tap a reply to see its English translation. Replies can be read aloud.
- "Say it better": your message rewritten a step richer, with every reply or on request.
- A topic for each conversation, a reply length setting, and a Conversations page to reopen or delete past conversations.

## What you need

- An Android phone, 64-bit (arm64), Android 8.0 or newer.
- Your own OpenAI API key. The app uses it for every turn and keeps it in the phone's secure storage; it goes nowhere else. [How to get one](https://github.com/Pitrified/fala-language-tutor/blob/main/docs/openai-key.md). The default model costs a fraction of a cent per turn.

## Install

1. Download `fala-0.1.0-arm64.apk` below on the phone.
2. Open it and allow your browser to install unknown apps when Android asks.
3. If an earlier test build is installed, uninstall it first: this release is signed with a different key, and Android refuses the update otherwise. Uninstalling deletes the stored key, conversations and settings.

Privacy policy: [docs/privacy-policy.md](https://github.com/Pitrified/fala-language-tutor/blob/main/docs/privacy-policy.md).
